# Prosa

Site da Prosa — tecnologia simples para o comércio de Rio Pomba e região (Zona da Mata, MG).

Protótipo estático, publicado via GitHub Pages.

## Estrutura
- `index.html` — página única, sem dependências além das fontes do Google.
- `img/` — imagens (crédito das fotos no rodapé da página).

## Créditos de imagem
Fotografias sob licença livre do Wikimedia Commons, creditadas no rodapé do site.
